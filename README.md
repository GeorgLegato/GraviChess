# ♟️ GraviChess

**3D Chess with a Twist of Gravity**

GraviChess reinvents the classic game by introducing gravity mechanics that warp space-time! Watch as pieces influence the board and each other in a stunning 3D environment.

## 🚀 Live Demo

**[Play GraviChess Now](https://georglegato.github.io/GraviChess/)**

## ✨ Features

-   **Gravity Mechanics**: Pieces have mass and can influence the trajectory of others (visual and gameplay effects).
-   **Immersive 3D Graphics**: Built with Three.js for a beautiful, interactive board.
-   **Dynamic Audio**: Sound effects for movement, captures, and game events.
-   **Modern Implementation**: Clean, module-based JavaScript architecture using Vite.

## 🛠️ Technology Stack

-   **Frontend**: HTML5, CSS3, Vanilla JavaScript
-   **3D Engine**: [Three.js](https://threejs.org/)
-   **Build Tool**: [Vite](https://vitejs.dev/)
-   **Deployment**: GitHub Pages (via GitHub Actions)

## 📦 Installation & Local Development

1.  **Clone the repository**
    ```bash
    git clone https://github.com/GeorgLegato/GraviChess.git
    cd GraviChess
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Start the development server**
    ```bash
    npm run dev
    ```

4.  **Build for production**
    ```bash
    npm run build
    ```
